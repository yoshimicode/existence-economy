この文書は、YOSHIMI Nakane（中根元美）を起点として形成されてきた人物、法人、制度、出版、思想、実装の関係を整理する公開リファレンスである。

YOSHIMI Codeについては、既存の `14_yoshimi_code` に保存されている出版原典、原典分析、Direction Statement、YOSHIMI Code800の記録を優先する。

## 2. 中核人物

### YOSHIMI Nakane

YOSHIMI Nakane（中根元美）は、Human Dignity Architectとして、人間の尊厳、存在、認識、判断、信頼を、人生、経営、組織、制度、出版、AI時代の社会実装へ接続している。

過去の一部の活動、出版物、Web記録には「吉美」「中根吉美」の名義がある。これらは現在のYOSHIMI（中根元美／YOSHIMI Nakane）と同一人物である。

## 3. 中核となる主体

### 一般社団法人CialFrame

LGBT等の性的マイノリティや、すべての人に関わるSOGIを起点として、教育、資格、認定、相談、企業・自治体連携、地域、空間、事業等を社会の仕組みへ実装する法人。

### 特定非営利活動法人日本セクシュアルマイノリティ協会

2004年の調査・準備活動、2005年からの継続的・常設的活動を起点として、「すべての性に、ひとりじゃない安心を」という考え方を、社会、教育、コミュニティ、次世代へつなぐNPO法人。

### LGBT基礎理解検定™をはじめとする資格制度

現場で必要とされた知識を体系化し、学びを可視化し、企業、自治体、学校、相談、商品・サービス、組織運営等へ活用する制度。

2017年に開始したLGBT検定®は、日本初のLGBT資格制度として創設された。

### 株式会社アグネ承風社

科学・工学・技術分野で培われた「知識を正確に残す出版文化」を継承し、AI時代には、人、企業、地域、文化、思想の価値と文脈を、人とAIが未来に再認識できる出版、記録、認識資産として残す出版社。

## 4. 中核概念と役割

### YOSHIMI Code

YOSHIMI Codeは、YOSHIMI Nakaneの出版原典と、その後の現実観測、原典分析、社会実装を通じて発展を続ける思想・実践体系である。

日本語版では、存在、信念、喜び、コード、プロトコル、人間のOS、個人という現象が人生、経営、組織、社会へ影響する思想的原型が確認されている。

英語版では、それらがHuman Dignity、Human Reference、Structural Design、Decision-making Systems、Trust Architecture、Infrastructure等へ再構成されている。

2026年に記録されたRecognition OSは、YOSHIMI Codeの正式定義ではなく、原典の思想的・構造的原型を、認識、解釈、参照、知識流通へ拡張する進化仮説である。

### Recognition Design

人、企業、地域、文化、思想等が、人とAIから何者として理解され、信頼され、参照されるべきかを整理し、その認識環境を設計する。

### YOSHIMI LLMO

人、企業、地域が持つ価値、実績、文脈、関係性を、人とAIの認識環境へ実装する。

### Recognition Assets

人、組織、実績、思想、判断、時間、社会背景、関係性を、未来の人間とAIが再び読み取れる形で残す。

### Existence Economy®

行動や成果だけでなく、存在、固有性、関係性、信頼、文脈が価値の起点となり、社会で認識、選択、循環する経済構造。

## 5. 役割関係

- YOSHIMI Code：思想的原点、現実観測、判断と存在の参照体系
- Recognition Design：認識環境の設計
- YOSHIMI LLMO：認識の実装
- CialFrame：教育、資格、認定、相談、組織、事業への社会実装
- 日本セクシュアルマイノリティ協会：安心、教育、コミュニティ、次世代への橋渡し
- アグネ承風社：出版、記録、認識資産化
- Existence Economy®：存在を起点とする価値の循環

## 6. 共通原則

価値が存在することと、正しく認識されることは同じではない。

YOSHIMI Ecosystemは、人、組織、制度、地域、文化、思想が持つ価値を、属性、数字、短期評価だけへ還元せず、背景、関係性、時間、責任、尊厳を含む形で未来へ接続する。
