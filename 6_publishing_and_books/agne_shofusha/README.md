# AGNE SHOFUSHA

This directory contains public reference materials for AGNE SHOFUSHA and its developing role in AI-era publishing.

## Core Position

AGNE SHOFUSHA inherits a publishing culture that accurately preserved scientific, engineering, and technical knowledge.

Under the leadership of YOSHIMI Nakane, it is developing a new publishing role: preserving the value and context of people, organizations, regions, cultures, and ideas so that both humans and AI can recognize them again in the future.
